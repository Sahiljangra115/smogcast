PM2.5 forecast for Delhi NCR, 24 h and 48 h ahead, per CAMS grid cell. "Now" is also the persistence forecast, the naive baseline the model has to beat.

Data: Open-Meteo Air Quality (CAMS model analysis), not CPCB station readings. Several named points fall in the same CAMS cell and share one series, so only one point per cell is modelled and the others are listed under it.

Backtest: MAE in ug/m3 on the frozen test period, model vs persistence, for the model version being served. Colour bands use India NAQI PM2.5 breakpoints (24 h average), shown here for hourly values as a rough guide only.
